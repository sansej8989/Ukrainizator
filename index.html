Українізатор

Автоматична українізація Windows в один прохід: мовний пакет, інтерфейс, регіональні стандарти, розкладки й дерусифікація — 12 кроків, один запуск.

завантаження...

Запускати в PowerShell від імені адміністратора. Завантажує останній перевірений реліз (не гілку в розробці), звіряє контрольну суму архіву й лише тоді запускає скрипт із диска.

Що робить

🇺🇦
Повна українізація
Мовний пакет, інтерфейс, регіон, часовий пояс, валюта ₴, розкладки — за один прогін.
🧹
Глибока дерусифікація
Прибирає ru-розкладку та додаткові ru-компоненти: мовлення, рукопис, OCR.
↩️
Відкат в один клік
Знімок налаштувань перед стартом і -Revert для миттєвого повернення.
🛡️
Безпечно за задумом
Точка відновлення, перевірка цілісності скрипта (SHA-256), захист від паралельного запуску.
🖥️
Будь-яка збірка Windows
Автоматичний вибір способу встановлення мови: сучасний API або запасний DISM-шлях.
⚙️
Тихий режим для флоту
-Silent -Mode All, -WhatIf для перегляду, віддалений запуск на список ПК.

Вимоги

  • ОС Windows 10 або Windows 11, будь-яка редакція крім Home (обмеження самої Microsoft на Language Packs)
  • PowerShell версія 5.1 або новіша (вбудована в сучасні Windows)
  • Права адміністратор
  • Інтернет потрібен для завантаження мовного пакету й самого релізу
